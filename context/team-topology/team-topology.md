# Team topology (illustrative, for the worked example)

A small slice, not the real Aurora topology. Enough for the worked example's triage agent to suggest
an owning team. Each row is a one-line team API: what the team owns and when to send something there.

| Team | Owns (team API summary) | Route here when |
|---|---|---|
| **Data Platform** | Datasets, data extracts, warehouse access, query help | the request is for data, an extract, or help querying |
| **IT Support** | Accounts, devices, software licences, access requests | the request is for access, hardware, or tooling |
| **Regional Analytics** | Region-specific market data and configuration | the request needs region-specific market knowledge |
| **Product Ops** | Internal process, request routing, "who owns this?" | it is unclear who owns the request |
