# Team-level context

**Owner:** the team (this table), with its users. This is the one kind of context the table
**authors** rather than consumes.

On the day, copy `templates/team-context.md` into this folder, rename it for your table, and fill it
in at stage 2. Everything else in the kit is here to be consumed or used; this is what you create.

See `worked-example/01-team-context.md` for a completed example.
