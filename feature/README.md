# `feature/` — your table's working folder

Everything your table produces during the day is saved here, as the skills run:

- `plan.md` — your session plan (`plan-the-session`)
- `problem.md` — the problem you landed on (`land-on-problem`)
- `frame.md` — the framed problem (`feature-spec`)
- `slice.md` — the slice you'll prototype (`shape-to-slice`)
- `prototype/` — the rough artefact(s) (`prototype-kickoff`)
- `retro.md` — what you learned and what's missing (`retro`)

At the end of the retro the agent **renames this folder to your idea's name**, so your work is traceable
to your table. The artefacts are kept and collaged into Aurora's context afterwards — not thrown away.
