# grill-me-with-docs (PLACEHOLDER — Stuart to supply)

This is a stand-in so the kit and the facilitator dry-run work end to end. **Stuart owns the canonical
`grill-me-with-docs` skill.** The interface below describes what the real skill needs to do, so his
version can drop straight in. A related `grill-me` skill already exists in the model-and-platform
workspace and can inform it.

> **Action for Stuart:** please share the canonical `grill-me-with-docs` skill so we replace this
> placeholder before the dry-run.

## Intended interface

- **Stage:** Build context and Frame (stages 2 to 3).
- **Inputs:** the context in this folder; whatever draft the team has so far.
- **Behaviour:** ask the team one sharp question at a time, challenging assumptions and checking each
  answer against the available context, until the thinking is clear and the gaps are named.
- **Output:** a sharpened draft and an explicit list of the assumptions or gaps that remain.

## Stand-in behaviour until replaced

If the real skill is not yet available, ask the team questions one at a time about their problem and
context, push back where an answer is vague or unsupported by the docs, and keep a running list of
open assumptions. Where the docs do not support an answer, say so and name who the team should ask,
rather than letting the gap pass as if filled.
